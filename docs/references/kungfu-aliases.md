# 心法别名映射与调研

核对日期：2026-11-24。唯一运行映射在src/services/jx3/kungfu_aliases.py，本文表格是该映射的说明。覆盖现有JJC catalog的32心法，并补齐其中未列出的少林防御心法洗髓经，共33个标准心法。不修改JJC统计目录。

## 来源与收录原则

- [2015新手心法介绍](https://jx3.17173.com/content/2015-04-04/20150404205218560_all.shtml)：冰心/冰秀、奶秀、花间/奶花、剑纯/气纯、铁牢、奶毒等早期常用称呼。
- [2013常用简称对照](https://jx3.17173.com/content/2013-02-06/20130206001254484.shtml)：BX/NX、QC/JC、ND/DJ、田螺TL/鲸鱼JY等字母与中文叫法。旧文有奶毒定位笔误，不采用其职业定位。
- [2025门派和体型俗称介绍](https://jx3.17173.com/content/07292025/112306248.shtml)：补充奶歌/药奶、四T及单心法门派归属。只采中性且能明确区分心法的称呼，不纳入体型或贬损外号。
- [魔盒配装大厅](https://www.jx3box.com/pz/public?mount=10243)：核对现代标准心法名称；当前导航含幽罗引、周天功等。
- [官方武学公告](https://jx3.xoyo.com/mobile/gg.html?id=1335478)：无相楼→幽罗引，藏剑包含问水诀和山居剑意。
- [官方万灵武学公告](https://jx3.xoyo.com/show-2466-6233-1.html)：万灵山庄→山海心诀。
- [官方段氏武学公告](https://jx3tc.xoyobox.com/show-98-768-1.html)：段氏→周天功。

“秀奶”为用户明确给定；其余治疗称呼的倒序形式、完整心法首字母（如ysxj）、无歧义的短名首字母及门派首字母，是本项目显式支持的输入约定，不宣称所有缩写都是网络通称。所有缩写人工维护，运行时不猜拼音；没有宣称穷尽全部社区外号。

## 用法与边界

装备/属性/装分均可用：`装备 桃桃白糖 bx PVE`、`装备 桃桃白糖 秀奶 PVP`、`属性 桃桃白糖 心法=NX 类型=PVP`。支持完整token、不区分英文大小写及全角英文；不用前缀、子串或模糊猜测。别名先转换为标准名后再查records/detail，因此与完整名使用相同缓存。裸参数置于角色后；已知完整服务器后的角色token优先为身份。未知显式心法报错，重复同义参数也报错。
