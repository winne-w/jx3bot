# JJC 数据中心统一入口需求

## 背景

当前 `jjc-ranking-stats.html`、`jjc-synced-matches.html`、`jjc-matchups.html` 是三个独立静态页面，用户必须知道具体 HTML 地址才能进入。三个页面都围绕 JJC 数据，但缺少统一品牌、导航和入口。

## 目标

新增统一站点入口 `public/index.html`，默认承载心法排名统计内容，并让三个页面通过统一导航互相访问。保留现有页面 URL、接口、查询逻辑和详情交互。

## 非目标

不合并三个页面的业务脚本；不改动后端 API、数据库、数据结构、查询语义和统计口径；不引入前端框架或构建流程。

## 验收标准

1. 访问 `/index.html` 能进入心法排名统计首页。
2. 统一导航可打开三个页面，当前页面有明显激活状态。
3. 三个页面均可通过统一站点标识返回首页。
4. 原有排名、角色查询、对局查询、胜率分析、弹窗、分页和导出交互继续可用。
5. 桌面和移动宽度下导航与页面内容不出现横向溢出。
