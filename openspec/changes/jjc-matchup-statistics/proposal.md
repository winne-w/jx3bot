## Why

现有 JJC 数据只能按角色浏览对局或按玩家统计最高分，无法按双方任意心法组合和队伍平均游戏分区间比较胜负数据。需要提供无固定主客方向的组合对阵统计与逐场分页入口，让用户研究指定分段内不同配置的实际胜率，并继续复用完整对局详情查看装备和奇穴。

## What Changes

- 新增对局级轻量统计投影，每场 3v3 对局保存一条可重建事实记录，包含双方心法组合、三人游戏分、队伍平均分、胜负及基础展示信息。
- 新增任意心法组合对阵查询：双方各可选择 0～3 个心法；空配置表示任意队伍，双方为空表示查询时间和分段内的全部对局。
- 支持最近 1、3、7、14、30 天和最长 90 天自定义时间范围，以及双方队伍平均游戏分都落入指定区间的筛选。
- 返回双方原始胜场、胜率、方向样本数、唯一对局数、双向命中数和缺失分数数，不输出优势结论。
- 分页返回唯一对局摘要，并通过现有对局详情接口继续查看六名玩家、装备和奇穴。
- 新增独立的组合对阵统计页面，查询条件可写入 URL 并支持交换双方配置。
- 提供历史投影 dry-run、显式写入和核验能力；新对局保存详情后实时刷新对局级投影。

## Capabilities

### New Capabilities

- `jjc-matchup-statistics`: 定义 JJC 3v3 心法组合对阵、队伍平均游戏分筛选、原始胜率统计、唯一对局分页和详情下钻行为。

### Modified Capabilities

无。

## Impact

- 数据库新增可重建的 `jjc_match_facts` MongoDB 集合及相应索引，需要历史回填与上线核验。
- 新增 storage repo、投影 service、组合查询 service、FastAPI 路由和独立静态页面，并接入现有对局详情保存链路。
- 现有 `jjc_match_detail` 仍是完整事实来源，`jjc_match_participants` 仍服务角色级读取；二者现有 API 行为不变。
- 需要同步 `README.md`、数据库设计和运行回归文档，并补充投影、统计、API、分页和前端测试。
