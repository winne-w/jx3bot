# JJC 心法查询来源 delta（本地实现完成，未部署）

## ADDED Requirements

### Requirement: 心法查询不使用 JX3API 兜底

系统 MUST NOT 在推栏心法查询未成功时请求 JX3API，或从 JX3API 竞技历史中提取心法。系统 MUST 保留合法本地胜场推断的身份、赛季与胜场约束，以及既有缓存读取规则。

#### Scenario: 推栏失败或身份不可用
- **WHEN** 榜单失败、角色未匹配、缺少查询身份、推栏返回空心法或抛出异常
- **THEN** 不请求 JX3API，直接尝试现有本地当前赛季胜场推断
- **AND** 本地没有合法结果时心法保持未知，不覆写已有有效缓存或伪造成功

#### Scenario: 已有缓存或推栏查询成功
- **WHEN** 原有规则允许复用缓存，或推栏成功返回心法
- **THEN** 按原有路径返回资料，保留成功资料的武器、队友和近期缓存预热行为

#### Scenario: 未知心法与普通竞技查询
- **WHEN** 有效排名角色最终心法未知
- **THEN** 不因此取消身份有效角色的正常同步资格
- **AND** 独立普通竞技查询可继续沿用既有 JX3API 能力
