# 14 日最高分排名赛季隔离修复需求

日期：2026-11-09。阶段：修复已实现、发布并验收；Git 改动保留本地，待提交归档。

## 背景与已验证问题

用户反馈线上“14日游戏最高分排名”包含上一赛季分数，要求出修复方案。只读公开 API 证实，2026-11-09 的 03:00:10 与 09:41:54 两个快照返回的前 1000 条最高分来源对局均早于本赛季 2026-11-05 开赛。两次响应分别覆盖已存结果与即时聚合路径。

## 目标与口径

最高分聚合使用最近 14 天窗口与快照所属赛季的交集，先过滤对局再按角色取最高分并排名。定时任务、即时聚合、缓存有效性、心法分布和详情统一。当前赛季旧结果定向重建，历史赛季结果保留。

共用聚合的 game 与 tuilan 同时修复；既有分数字段含义、按本地已同步参与者统计的对象与前 1000/200/100/50 范围不变。仅旧赛季比赛的角色不入本赛季榜，有本赛季比赛的角色按本赛季最高分重新参与排名。

## 范围与交付

涉及最高分 service、参与者与结果 repo、两个只读 API、定时任务装配、两个 HTML 入口以及定向重建工具和相关文档。具体方案与线上证据见 design.md。

初始请求交付方案；同日用户明确要求“按照这个方案处理修复”，授权继续实现、验证与线上恢复。已补充 tasks.md、规格 delta、测试与复核记录，实施及验收见 acceptance.md；生产配置未改动。

## 验收结果要求

本赛季修正结果中开赛之前的最高分来源为 0；角色最高分、排名与计数从过滤后的全量候选重新生成；分布及详情一致；旧跨季 done 结果不能继续命中；缓存缺失不能重新生成跨季结果；旧赛季快照不因套用当前边界而被清空。

## 非目标与证据边界

不删除旧赛季原始对局，不补抓全部缺失比赛，不修改同步队列或当前推栏榜统计，不建设历史完整赛季配置表。尚未比对生产源码和 Mongo 原始投影，正确榜单人数及分数需在实现后的 dry-run 中核定。
