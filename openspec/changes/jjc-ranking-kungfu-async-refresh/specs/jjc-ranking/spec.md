## ADDED Requirements

### Requirement: 排名批量复用角色心法

系统 MUST 在新模式启用时批量解析榜单身份并读取 `role_identities.jjc_kungfu`。只有身份、赛季名称及起点、3v3、算法、版本和时间合法且未超过最大年龄的结果可参与心法分布。名称回退 MUST 验证榜单已有ID，不能按同名混用。

#### Scenario: 全榜已有可用心法
- **WHEN** 当前榜单角色均有匹配作用域的成功结果
- **THEN** 批量选取并固定本次采用值，不逐人外呼、睡眠或重复读取身份
- **AND** stale结果可用于本次统计并由后台更新

#### Scenario: 同名但ID冲突
- **WHEN** 名称候选与榜单已知角色ID冲突
- **THEN** 角色心法记未知，不把另一角色结果计入当前分布，不隐式合并身份

### Requirement: 缺失心法当前统计直接查询

系统 MUST 逐角色判断缓存；可用值直接复用并登记周期刷新，没有可用值 MUST 在当前统计按名次等待直接查询，不得仅入异步队列后留下unknown。直接查询成功后 MUST 保存角色心法并立即计入本轮。安全身份不可解析时使用榜单定位直接查询，不合并冲突身份。实际查询失败可以保留unknown并继续后续角色。

#### Scenario: 冷缓存及后台关闭
- **WHEN** 角色没有可用心法，后台消费者关闭或该角色正在退避
- **THEN** 当前统计直接查询该角色，成功后立即参与分布并供后续缓存复用
- **AND** 无前10人/30秒总补齐上限，外部鉴权失败或限流冷却仍生效

#### Scenario: 前后台发布并发及确认失败
- **WHEN** 直接查询与旧后台任务重叠，或角色发布成功后队列确认失败
- **THEN** 共享角色代次和token防旧结果覆盖新成功值，读回已确认的本代次结果可用于当前统计，未确认队列按租约恢复

### Requirement: 时效与历史快照可解释

系统 MUST 采用统一刷新周期和最大可用年龄，区分fresh/stale/unknown并冻结实际采用值、验证时间、来源及版本。后台刷新 MUST 仅影响后续统计。各范围人数 MUST 守恒，coverage按可用数/总数计算，空范围为null。

#### Scenario: 统计后主打心法变化
- **WHEN** 快照使用云裳而后台随后发布冰心
- **THEN** 原快照仍为云裳，后续统计可采用冰心及新验证时间

#### Scenario: 最大年龄边界
- **WHEN** 结果年龄等于最大年龄或刚超过最大年龄
- **THEN** 前者可用并按刷新周期判为fresh或stale，后者为unknown并保持原始排名

### Requirement: 辅助信息缺失不得误导

系统 MUST 防止旧装备/队友字段覆盖新心法及其规范ID。无法确认的辅助数据 MUST 保持unknown/unchecked；若原展示无法表达不完整，标注或隐藏对应指标，不把缺失当非橙武或输出误导0%。本次不引入新的装备比例分母版本。

#### Scenario: 新心法无对应装备信息
- **WHEN** 本轮心法为冰心而旧辅助数据只对应云裳
- **THEN** 不沿用其心法ID或伪装装备已检查，最小显示资料不完整

### Requirement: 旧入口与失败处理兼容

系统 MUST 在新统计关闭时保留原入口行为；显式历史tag走原流程且不登记当前活跃任务。仅后台开关启用时也能从当前榜单登记预热。旧快照缺少时效字段 MUST 可读取；网页（含成员详情和导出）及QQ图片仅显示覆盖率及未知人数，不显示fresh/stale/时效提示，缺少覆盖数据时显示“心法覆盖率未记录”。登记失败可标降级保留已读值，读取失败 MUST 报统计失败。

#### Scenario: 后台预热与历史tag
- **WHEN** 仅启用后台刷新，随后当前榜单和显式历史tag分别被查询
- **THEN** 当前榜单可登记预热，历史tag不登记当前任务

#### Scenario: Mongo异常
- **WHEN** 只登记失败或角色结果读取失败
- **THEN** 前者保留已读结果并标refresh_degraded，后者不伪装全未知成功

#### Scenario: 旧快照和关闭开关
- **WHEN** 读取旧快照或关闭新模式
- **THEN** 原入口和历史展示继续可用，缺失时效不默认为fresh

#### Scenario: 页面与QQ图片隐藏心法时效
- **WHEN** 生成网页统计、成员详情、导出图片或QQ合图/拆分图
- **THEN** 保留心法覆盖率及未知人数，不显示新鲜、待刷新或未记录时效
- **AND** 旧快照或空范围缺少覆盖数据时显示“心法覆盖率未记录”，底层快照/API中的时效数据与有效性判断保持原口径
