# 全站模板图片与 HTTP 页面视觉风格统一需求

日期：2026-11-26
状态：已完成开发实现、双版本单测、Playwright 全量离线渲染巡检与独立代码审查（待用户验收合入）。

## 1. 背景与痛点

当前 JX3Bot 生成的 QQ 模板图片与对外 HTTP 页面在多次迭代中形成了多套割裂的视觉风格与画布规格：

1. **QQ 模板图片存在 6 类不同风格与多种过宽画布**：
   - `竞技排名` 统计合图（`1120px`）与 8 张拆分图（`800px`）：浅灰白底 + 蓝粉高饱和渐变柱条；合图为双列宽图，在手机 QQ 聊天窗内缩略字号偏小。
   - `装备查询`（`origin/main` 已上线版本）：`760px`（`380px @2x`）移动端竖屏窄卡，但采用深暗紫檀底色（`#261e2c`），与其余浅色图片风格不一致。
   - `竞技查询`（`955px`）、`百战角色查询`（`640px`）、`烟花查询`（`1194px`）、`资历查询`（`800~1120px` 及 `225*N` 动态拉宽）：高饱和天蓝渐变背景 + 半透明玻璃白卡 + 亮青表头。
   - `奇遇查询`（`870px`）、`交易行查询`（`800px`）、`副本查询`（`800px`）：早期纯白无背景裸表格/网格、低清内嵌 JPEG base64 小图标、硬编码糖果绿（`#A3E4D7` / `#ABEBC6`）色块。
   - `万宝楼查询`（`810~820px`）及超长订阅列表裸 `<pre>` 截图：灰底 `#f5f5f5` + 传统 6 列直角宽表，手机端阅读拥挤。
   - `百战查询`（`1500px` 深蓝 `#1c2130` 棋盘）与 `帮助 qun.html`（`810px` 直角本地背景图死链 + 黑色半透明遮罩）：各自独立。
2. **HTTP 网页端存在内外不一致**：
   - `public/index.html`（同 `jjc-ranking-stats.html`）、`jjc-synced-matches.html`、`jjc-matchups.html` 虽共用 `jjc-site.css` 顶栏，但内部面板圆角（`8px` vs `18~28px`）、渐变按钮、斜纹背景遮罩及配色细节不统一。
   - `public/jjc-sync-queue.html` 仍为独立后台蓝灰工具风（`#f5f6f8` / `#2563eb` / `6px` 小圆角），未接入统一站点顶栏与视觉体系。

## 2. 已确认目标范围（用户澄清结论）

1. **统一基准风格**：选定 **「清爽现代浅色风」**——全站（全部 22 个活跃 QQ 模板竖卡 + JJC 全部 5 个 HTTP 页面）统一采用微冷云白底（`#F3F6FB`）+ 纯白圆角卡片（`#FFFFFF`）+ 澄澈靛蓝主色（`#4F6EF7`）+ 统一语义色/品质色/等宽数字字阶。
2. **QQ 模板图片全量覆盖并统一移动端竖屏窄卡**：
   - 覆盖全部 22 个活跃 QQ 图片模板及网页截图通用页脚（`jx3web`）。
   - 画布规格全面统一为 **`width=760, height="ck"`（等效 `380px @2x` 移动端双倍设计网格，物理输出 `1520px` 宽）**，单列纵向排布，手机 QQ 免点开即可清晰阅读。
   - 统一顶部信息头栏与底部品牌签名栏（`【夏鸥】bot`），并全量开启 Jinja `{% autoescape true %}`。
3. **HTTP 页面全量覆盖（全部 5 个静态页面）**：
   - 统一 `public/index.html`、`public/jjc-ranking-stats.html`、`public/jjc-synced-matches.html`、`public/jjc-matchups.html` 视觉与交互细节，保持 `index.html` 与 `jjc-ranking-stats.html` 完全一致。
   - 将 `public/jjc-sync-queue.html` 接入 `jjc-site.css` 统一浅色视觉壳层、顶栏品牌与标题区，但**不在其余 4 个公开页面顶栏导航中暴露 `jjc-sync-queue.html` 入口**（公开导航维持 `心法排名` · `对局查询` · `心法对阵` 3 项）。

## 3. 非目标与兼容边界

- 不改变业务逻辑与数据口径。
- 不改变 HTTP API 契约与数据库结构。
- 不破坏前端既有交互契约与单测切片锚点。
- 不污染既有 dirty 工作区（在独立 git worktree 中基于最新 `origin/main` 开发验证）。
