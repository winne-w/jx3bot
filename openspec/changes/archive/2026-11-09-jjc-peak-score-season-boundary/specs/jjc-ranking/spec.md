## ADDED Requirements

### Requirement: 最高分排名不得跨越快照所属赛季
系统 MUST 将最高分候选对局时间范围限制为最近十四天与快照所属赛季的交集，再按角色取最高分、排序和截取。game/tuilan、来源计数、分布和详情 MUST 使用相同范围。

#### Scenario: 新赛季未满十四天
- **WHEN** 同一角色同时存在上赛季高分和本赛季低分
- **THEN** 只用本赛季最高分参与重新排名
- **AND** 仅有上赛季比赛的角色不进入本赛季榜单

#### Scenario: 旧缓存或查询超时
- **WHEN** 当前赛季 done 结果缺少/不匹配 season_bounded_v1 元数据，或缓存查询发生应用/数据库执行超时
- **THEN** 不返回旧跨季结果，按已核实的赛季窗口只读聚合
- **AND** 读取列表和心法详情使用统一编排

#### Scenario: 历史赛季与写入失败
- **WHEN** 读取旧赛季已存 legacy 或带持久化赛季边界的结果
- **THEN** 保留其历史视图，不套用当前开赛日期
- **AND** 未知历史边界不猜测重算，生成或写入失败不覆盖原有效结果、不报告成功

#### Scenario: 定向存量重建
- **WHEN** 使用重建工具选择当前配置赛季
- **THEN** dry-run/verify 仅读取，apply 前验证全部选定快照的所属赛季，并按同一窗口重建两类分数
- **AND** 每个已发布排名项时间合法、名次连续、角色唯一，任一失败返回非零退出码
