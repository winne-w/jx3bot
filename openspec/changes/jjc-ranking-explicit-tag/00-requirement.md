# QQ 竞技排名手动指定 tag

目标：QQ 竞技排名命令可携带 tag=<正整数>，直接查询对应排行榜并跳过时间标签接口。省略参数保留现有行为：优先读取默认缓存，未命中使用时间标签响应 data.defaultWeek（不是计算列表最大值）。

支持竞技排名、竞技排名统计、竞排名，现有拆分、缓存心法、橙武占比、debug 选项可任意排序。空值、非整数、非正整数、重复 tag 提示用法，不调用业务查询。

tag 是接口原始值，不是赛季周次。历史排行榜的心法仍按现有统计方式获取，不承诺历史心法快照。非目标：HTTP API、定时任务、数据库结构及历史赛季解析重构。
